# E-Commerce Sales Data Analysis

## Project Overview
This project analyzes e-commerce sales data
to identify business trends and performance.

## Tools Used
- Microsoft Excel
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- MySQL
- Power BI

## Project Objectives
- Analyze total sales and profit.
- Identify top-selling products.
- Analyze regional performance.
- Study monthly sales trends.
- Build an interactive dashboard.

## Project Workflow
1. Dataset Generation
2. Data Cleaning
3. Exploratory Data Analysis
4. SQL Analysis
5. Power BI Dashboard
6. Business Insights

## Dataset
Contains 1,000+ sales records.
